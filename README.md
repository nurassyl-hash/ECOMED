# EcoMed AI

Веб-приложение для учёта домашних лекарств: распознавание упаковки по фото или
ручной ввод, поиск дубликатов по действующему веществу (МНН), контроль сроков
годности, проверенная информация об утилизации и подтверждённая экономия.

> Приложение не ставит диагноз, не назначает лечение и не предлагает заменять
> один препарат другим. Все числовые показатели считаются кодом; языковая модель
> только объясняет уже рассчитанные агрегаты и проходит фильтр безопасности.

## Возможности
- Семейная аптечка с изоляцией доступа по `household_id`.
- Добавление препарата: по фото (OCR/структурирование) **или** вручную.
- Проверка перед покупкой с уровнями совпадения A–D и пояснением о невзаимозаменяемости.
- Контроль срока годности (expired / critical / soon / ok / unknown) и срока после вскрытия.
- Поиск дубликатов по нормализованному набору МНН.
- Аналитика и отчёт с экспортом в Markdown.
- Утилизация: правила из одобренной базы, карта, метки demo/verified, отметка передачи.

## Стек
Streamlit · Pydantic · SQLAlchemy + SQLite · OpenAI Agents SDK (vision/text) · RapidFuzz.

## Запуск (локально)
```bash
conda activate practical-ai-engineering        # или любой venv c Python 3.11+
pip install -r ecomed/requirements.txt
cp ecomed/.env.example ecomed/.env              # OPENAI_API_KEY — опционально
streamlit run ecomed/app.py
```
Приложение работает и **без** ключа LLM: распознавание фото переключается на
ручную форму, а пояснение к отчёту формируется детерминированным текстом.

## Деплой (Streamlit Community Cloud)
- Main file path: `ecomed/app.py`
- Ключ добавляется в **Secrets** панели деплоя (не в репозиторий):
  `OPENAI_API_KEY = "..."`

## Переменные окружения (`ecomed/.env`)
| Переменная | Назначение | По умолчанию |
|---|---|---|
| `OPENAI_API_KEY` | ключ vision/text LLM; пусто → ручной режим | — |
| `ECOMED_VISION_MODEL` | модель распознавания фото | `gpt-4o` |
| `ECOMED_TEXT_MODEL` | модель пояснения к отчёту | `gpt-4o-mini` |
| `ECOMED_DB_PATH` | путь к SQLite | `ecomed.db` |
| `ECOMED_DEFAULT_CITY` | город по умолчанию | `Алматы` |

## Тесты
```bash
pytest ecomed/tests -q
```
Покрыты: статусы срока и `effective_expiry`, нормализация МНН и уровни A–D,
запрет отрицательного остатка, изоляция доступа, JSON-схема распознавания,
фильтр формулировок, интеграция «добавить → проверить → отчёт».

## Структура
```
ecomed/
  app.py                     Главная (дашборд)
  pages/                     Аптечка, Добавить, Проверить, Анализ, Утилизация, Семья, Настройки
  services/                  inventory, matching, report, disposal, scan
  integrations/              ocr_provider (vision-LLM), catalog_provider, ...
  policies/medical_safety.py дисклеймер, системный промпт, пост-фильтр
  domain.py                  детерминированное ядро (сроки, МНН, уровни A–D)
  models/schemas.py          Pydantic-схемы
  db/                        модели, сессия, seed
  data/                      демо-CSV
  assets/                    логотип и изображения
  tests/
```

## Данные
`ecomed/data/*.csv` — демонстрационные каталог, цены и пункты приёма (с честными
метками). При первом запуске создаётся демо-набор; данные хранятся в SQLite и
переживают перезапуск. Демо-данные не являются «живыми» источниками.
