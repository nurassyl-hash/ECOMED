# EcoMed AI — отчёт о проделанной работе

*Подробное описание проекта простыми словами: что это, зачем, как устроено и что было сделано по шагам.*

---

## 1. Что это за приложение (простыми словами)

**EcoMed AI** — это сайт (веб-приложение), который помогает семье вести «умную домашнюю аптечку». Представь ящик с лекарствами дома: там лежат таблетки, сиропы, мази. Обычно никто не знает точно, что там есть, что скоро испортится и что уже просрочено. Из-за этого:

- покупают второй раз то, что уже есть дома (тратят деньги зря);
- находят лекарство, когда срок годности уже вышел (его нельзя использовать);
- не знают, куда сдать просроченные лекарства, чтобы не навредить природе.

EcoMed AI решает эти проблемы: он показывает список всех лекарств, следит за сроками, находит одинаковые препараты и подсказывает, где безопасно сдать ненужные лекарства.

> **Важное правило:** приложение **не лечит и не ставит диагноз**. Оно только ведёт учёт лекарств — как «умный блокнот». Все вопросы о лечении — только к врачу или фармацевту.

## 2. Что умеет приложение (главные функции)

1. **Добавить лекарство** — сфотографировать упаковку (приложение само распознает название и срок) **или** ввести данные вручную.
2. **Список аптечки** — видеть все лекарства, искать по названию, фильтровать по сроку и месту хранения.
3. **Контроль срока годности** — приложение красит лекарства по цветам: 🔴 просрочено, 🟠 меньше месяца, 🟡 1–3 месяца, 🟢 всё хорошо, ⚪ срок неизвестен.
4. **Проверка перед покупкой** — перед походом в аптеку можно проверить, нет ли уже такого лекарства дома.
5. **Поиск дубликатов** — находит лекарства с одинаковым действующим веществом (например, «Панадол» и «Парацетамол» — это одно и то же вещество).
6. **Отчёт и аналитика** — показывает, сколько всего лекарств, сколько скоро истекает, сколько денег сэкономлено.
7. **Безопасная утилизация** — показывает реальные пункты приёма просроченных лекарств (в Алматы — настоящие адреса поликлиник).
8. **Сравнение цен** — показывает цены на лекарства в разных аптеках города, чтобы купить дешевле.

## 3. Как устроено приложение (архитектура простыми словами)

Приложение можно сравнить с рестораном:

| Часть приложения | Что делает | Сравнение |
|---|---|---|
| **Интерфейс** (страницы) | То, что видит человек: кнопки, таблицы, формы | Зал ресторана и меню |
| **Логика** (сервисы) | Считает сроки, ищет дубликаты, сравнивает цены | Повар на кухне |
| **База данных** | Хранит все лекарства, чтобы они не потерялись | Кладовка с продуктами |
| **ИИ-помощник** | Читает текст с фото упаковки | Помощник, который умеет читать этикетки |
| **Правила безопасности** | Следит, чтобы приложение не давало медицинских советов | Охранник, который проверяет правила |

Главная идея: **все числа считает обычный код (он точный и проверяемый), а искусственный интеллект только помогает читать фото и пересказывать готовые цифры человеческим языком.** Так мы уверены, что приложение не выдумает опасный совет.

## 4. Что было сделано — по шагам (этапы работы)

### Этап 1. Изучение задания
Прочитали техническое задание (документ с описанием, что должно уметь приложение). Составили план и проверили, какие инструменты уже установлены на компьютере.

### Этап 2. Каркас и база данных
Создали «скелет» приложения и базу данных (кладовку для лекарств). Придумали таблицы: пользователи, семьи, лекарства, события (добавил/использовал/выбросил), пункты утилизации, цены. Настроили правило: количество лекарства **не может быть отрицательным**.

### Этап 3. Добавление лекарств
Сделали страницу «Добавить». Здесь можно:
- **Сфотографировать** упаковку — ИИ читает название, дозировку, срок годности и заполняет форму. Если он в чём-то не уверен — подсвечивает жёлтым, чтобы человек проверил.
- **Ввести вручную** — если фотографировать не хочется, просто заполнить поля самому.

Если ИИ ничего не распознал — приложение **не выдумывает** данные, а просит ввести вручную.

### Этап 4. Сроки годности
Написали точные вычисления срока годности. Если лекарство уже открыли (например, сироп), берётся **более ранняя** из двух дат — на упаковке или «годен после вскрытия». Каждому лекарству присваивается цвет-статус.

### Этап 5. Поиск дубликатов и проверка покупки
Научили приложение понимать, что «Панадол» и «Парацетамол» — одно вещество. Для этого названия приводятся к единому виду (даже если написано русскими и латинскими буквами). При проверке покупки приложение показывает уровень совпадения:
- **A** — точно такая же упаковка уже есть;
- **B** — то же вещество, дозировка и форма;
- **C** — совпадает только вещество;
- **D** — просто похожее название.

При этом приложение честно предупреждает: «это **не значит**, что лекарства можно заменять — спросите врача».

### Этап 6. Отчёты и аналитика
Сделали страницу «Анализ»: таблицы и графики со сроками, дубликатами, экономией. Отчёт можно скачать файлом. Числа считает код, а ИИ только красиво их пересказывает (и проходит проверку безопасности).

### Этап 7. Безопасная утилизация
Сделали страницу с пунктами приёма просроченных лекарств.
- Для **Алматы** взяли **36 настоящих адресов поликлиник** из официальной статьи (они открылись в июне 2025). У каждого — реальный адрес, что принимают, ссылка на источник и метка «🟢 подтверждён». Координаты для карты получили автоматически через сервис карт.
- Для остальных 19 городов Казахстана оставили демонстрационные (вымышленные) пункты с честной пометкой «🟡 демонстрационный — не использовать как адрес».

### Этап 8. Сравнение цен в аптеках
Добавили функцию сравнения цен:
- в **боковой панели** можно выбрать город и сразу увидеть, где лекарство дешевле;
- на **отдельной странице** — большая таблица со всеми препаратами, самой низкой ценой и экономией.

Придумали демонстрационные цены: 14 препаратов в 5 вымышленных аптеках в 3 городах. Также сделали **заготовку** в коде, чтобы в будущем можно было подключить настоящий сервис цен (просто «вставить» его вместо демо-данных, ничего больше не переписывая).

### Этап 9. Медицинская безопасность
Добавили «фильтр-охранник»: если ИИ вдруг попытается написать что-то вроде «примите это лекарство» или «замените на другое», фильтр это заметит и заменит на безопасный текст. Так приложение никогда не даёт опасных советов.

### Этап 10. Дизайн
- Встроили **логотип** проекта (зелёная иконка с листом и медицинским крестом).
- Добавили красивую **главную страницу** с картинкой на аптечную тему.
- Применили **фирменные зелёные цвета** ко всем страницам (кнопки, заголовки, меню).

### Этап 11. Проверка (тесты)
Написали **27 автоматических тестов** — маленьких программ, которые сами проверяют, что всё работает правильно: верно ли считаются сроки, находятся ли дубликаты, нельзя ли увести количество в минус, срабатывает ли фильтр безопасности. Все 27 тестов проходят успешно. Также проверили каждую страницу в реальном браузере — ошибок нет.

### Этап 12. Подготовка к публикации
Настроили проект так, чтобы его можно было выложить в интернет для проверяющих. При этом:
- **секретный ключ** и личные данные **не попадают** в публикацию (лежат в отдельном защищённом файле);
- лишние и личные документы исключены из публикации;
- написали инструкцию по запуску (файл README).

## 5. Инструменты и технологии (с простым объяснением)

| Инструмент | Что это и зачем | Простыми словами |
|---|---|---|
| **Python** | Язык программирования | Язык, на котором «написано» всё приложение |
| **Streamlit** | Библиотека для сайтов на Python | Позволяет быстро сделать сайт с кнопками и таблицами |
| **SQLite** | Небольшая база данных | «Кладовка», где хранятся лекарства; не теряется после выключения |

| **Pydantic** | Проверка данных | Следит, чтобы данные были правильного вида (например, дата — это дата) |
| **OpenAI (ИИ / LLM)** | Искусственный интеллект | Читает текст с фото упаковки и пересказывает отчёт человеческим языком |
| **OpenAI Agents SDK** | Инструмент для работы с ИИ | Помогает получать от ИИ строгий, аккуратный ответ |
| **RapidFuzz** | Сравнение похожих слов | Находит похожие названия лекарств |
| **Pandas** | Работа с таблицами | Удобно показывает данные в виде таблиц |
| **Pillow** | Работа с картинками | Обрезали логотип, подготовили фото |
| **Plotly / графики Streamlit** | Диаграммы | Рисуют графики в отчёте |
| **OpenStreetMap (Nominatim)** | Карты и координаты | Нашли координаты реальных адресов Алматы для карты |
| **pytest** | Автоматические тесты | Программы, которые сами проверяют, что всё работает |
| **Playwright** | Проверка сайта в браузере | Автоматически открывает страницы и ищет ошибки |
| **Git** | Хранение версий кода | «Машина времени» для кода: можно сохранять и откатывать изменения |

## 6. Из чего состоит проект (файлы)

```
ecomed/
  app.py                     — Главная страница (обзор аптечки)
  pages/                     — Остальные страницы:
      01_inventory.py            моя аптечка
      02_add.py                  добавить лекарство (фото или вручную)

      04_analysis.py             анализ и отчёт
      05_disposal.py             безопасная утилизация
      06_family.py               семья и роли
      07_settings.py             настройки

  models/schemas.py          — описание, как должны выглядеть данные

  tests/                     — автоматические тесты
  docs/                      — этот отчёт
  README.md                  — инструкция по запуску
```

## 7. Как запустить приложение

```bash
pip install -r ecomed/requirements.txt   # установить нужные библиотеки
streamlit run ecomed/app.py              # запустить сайт
```

После запуска сайт открывается в браузере. Приложение работает даже **без** ключа ИИ — тогда лекарства просто добавляются вручную.

## 8. Безопасность

- **Медицинская:** приложение не ставит диагноз, не назначает лечение, не советует заменять лекарства. Есть фильтр, который блокирует опасные фразы.
- **Данные:** список лекарств может косвенно рассказать о здоровье, поэтому приложение хранит минимум данных, а секретные ключи держит отдельно и **не** выкладывает в интернет.
- **Честность данных:** демонстрационные (придуманные) данные всегда помечены. Реальные адреса — только с указанием источника.
